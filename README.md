+# Yogesh Portfolio
+
+A responsive personal portfolio website for **Yogesh**, an AI developer, Python learner, researcher, and creator of the COSMOS Ecosystem.
+
+## Live Website
+
+[Visit the portfolio](https://sathishyogesh20-del.github.io/MY_PORTFOLIO/)
+
+## Features
+
+- Responsive portfolio design
+- AI developer hero section
+- About, skills, achievements, projects, and contact sections
+- Violet and blue theme switcher
+- Theme preference saved with `localStorage`
+- Animated section and card reveals
+- Scroll progress indicator
+- Typing animation
+- Interactive card tilt effects
+- Reduced-motion accessibility support
+- SEO metadata and Open Graph tags
+- Schema.org structured data
+- Sitemap and robots.txt files
+- Contact form connected to FormSubmit
+
+## Technologies Used
+
+- HTML5
+- CSS3
+- JavaScript
+- Google Fonts
+- Font Awesome
+- FormSubmit
+- GitHub Pages
